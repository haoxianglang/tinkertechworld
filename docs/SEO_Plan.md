## Implemented
- Unique titles, meta descriptions and one H1 per page.
- Canonical absolute HTTPS URL, reciprocal en-CA / zh-Hans / x-default alternate links.
- JSON-LD EducationalOrganization on Home using known brand/contact/city data only; WebPage on inner pages.
- Open Graph and Twitter large-image metadata; existing image described as a concept illustration.
- Generated XML sitemap for canonical public pages in both languages; excludes 404. The legacy `/store.html` fabrication-service page was retired on 2026-09-17 once its listed services became taught courses; it no longer exists and returns 404.
- robots.txt with sitemap discovery, no tracking parameters in canonical URLs.
- Semantic links and HTML content without reliance on JS rendering; image alternative text and explicit dimensions.
- Existing About, Makerspace and Competitions URLs retained with relevant current content.

## Intentionally withheld
No AggregateRating, Review, Product Offer, Event, actual CourseInstance, team registration, exact address, business hours or fees in structured data until evidenced. No FAQ rich-result promise. No inflated rankings or conversion claims. robots rules are crawl guidance, not an access-control mechanism; internal source contains no personal lead data.
