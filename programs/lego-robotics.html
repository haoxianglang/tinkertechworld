What learning looks like

Skills with a purpose.

Grades 3–6

A hands-on first step into robotics. Learners build sturdy LEGO structures, connect motors and sensors, and use block-based coding to bring their robot to life. Each session pairs a short building challenge with a coding lesson, so ideas keep moving from block diagram to working machine.

Learning outcomes

  • Build stable, functional structures using gears, axles and motors
  • Use block-based coding to control movement: forward, turn, stop
  • Read and respond to a simple sensor input, such as touch or colour
  • Test one change at a time and explain what happened
  • Practise teamwork and problem-solving during a build challenge

Grades 7–9

Building on core construction and coding skills, learners take on more advanced control challenges—combining multiple sensors, writing longer sequences and loops, and refining a robot’s reliability through repeated testing. Sessions move from guided challenges toward more open-ended problems that reward planning and debugging.

Learning outcomes

  • Combine multiple sensor inputs to control robot behaviour
  • Write and debug longer coding sequences, including loops and conditionals
  • Calibrate a robot’s response for more consistent, repeatable results
  • Break a complex task down into smaller, testable steps
  • Explain design decisions and propose improvements based on test results

Illustrative project · Not a student result

Build a delivery robot

Design a robot to carry an object to a target. Compare routes, adjust the mechanism and record what improves each attempt.
