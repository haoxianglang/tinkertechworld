UV 打印

直接印在物体表面，用紫外光固化。

学习 UV 打印机如何将油墨直接印在亚克力、木材、金属等硬质或软质表面，并用紫外光即时固化。探索材质、油墨层次与效果之间的关系。

建议学习阶段
7–9 年级 · 高中 · 成人
学习形式
指导下开展项目学习
排期与学费
报名前请向 TTW 确认

学习内容

让技能发挥作用。

学生了解 UV 打印机如何将油墨直接印在亚克力、木材、金属等表面，并用紫外光即时固化。在此过程中，为特定材质与印刷范围准备设计文件，在样品材料上测试打印参数，并将成品与原设计进行比较。

学习成果

  • 为特定材质与印刷范围准备设计文件
  • 说明 UV 固化油墨的层次、光泽与质感如何影响成品
  • 在样品材料上测试打印参数，再进行正式打印
  • 在操作 UV 打印设备时遵循安全规范
  • 将成品的颜色与效果与原设计比较并作出调整

适合自己的学习起点。

这是一项涉及打印设备操作的动手技能课程。适合年龄、班级人数和设备使用安排将在报名前单独确认。
