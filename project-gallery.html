Ideas worth
getting your hands into.

Explore the kinds of challenges in TTW’s learning plans. These are illustrative project ideas, not completed student work.

Illustrative project

Build a delivery robot

Design a robot to carry an object to a target. Compare routes, adjust the mechanism and record what improves each attempt.

Explore the pathway →
Illustrative project

Prepare a RoboMission-style challenge run

Build and program a robot to complete a themed mission field within a time limit, then refine it across repeated timed runs—the core loop behind most WRO categories.

Explore the pathway →
Illustrative project

Prototype one device, four perspectives

Take one simple device and look at it four ways: how a computer scientist would model its logic, a computer engineer would design its circuit and firmware, an electrical engineer would handle its power and signals, and a mechanical engineer would design its housing and moving parts.

Explore the pathway →
Illustrative project

Make a custom robot attachment

Sketch an attachment, model its dimensions and consider how it fits. Test a prototype and revise the design using measurements.

Explore the pathway →
Illustrative project

Design and press a custom transfer

Design a small graphic, prepare the file for DTF printing, and press it onto a sample fabric piece. Compare results and adjust settings for a cleaner result.

Explore the pathway →
Illustrative project

Print a custom design on a rigid surface

Choose a small object or material sample, prepare a design file sized to fit it, and print a test piece. Compare colour and finish against the original design and adjust.

Explore the pathway →
Illustrative project

Build a robot that reacts to its surroundings

Build a robot with a sensor, then program it to respond—stop, turn or speed up—based on what the sensor detects. Test it in a few different situations and adjust.

Explore the pathway →
Illustrative project

Complete a full practice test and score review

Take a timed, full-length practice test across all four sections, then review the results section by section to identify the highest-impact areas to improve before the next attempt.
