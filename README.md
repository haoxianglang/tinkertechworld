# Tinker Tech World

Tinker Tech World（TTW）鼓励学习者通过动手制作、探索与实践，培养创造力、解决问题的能力，以及对科技的理解。

本网站提供 TTW 的课程介绍、学习方向、项目展示和联系信息，支持英文与简体中文，方便不同年龄段的学习者及家长了解 TTW。

Tinker Tech World (TTW) encourages learners to explore technology through hands-on projects, creative thinking, and practical problem solving.

This website introduces TTW’s programs, learning pathways, projects, and contact information in English and Simplified Chinese.
